Projects

AI Smart Civic Services

A hackathon app where citizens report civic problems and a scikit-learn model sorts each complaint into the right department. Deployed on Streamlit Cloud.

Pythonscikit-learnStreamlitSQLite
  • Complaint classifier sorts reports into Road, Water, Drainage, Waste, Electricity and Safety.
  • Each complaint moves through Open, Assigned, In Progress and Resolved.
  • Complaints are stored in a SQLite database; the dashboard has a dark, animated theme.

Dialysis Need Predictor

A website that predicts whether a patient may need dialysis from kidney disease data. It is a learning project and not medical advice.

Pythonscikit-learnFastAPIHTML frontendDocker
  • Model trained on a kidney disease CSV dataset.
  • FastAPI backend serves predictions to a plain HTML frontend.
  • Packaged with Docker and deployed on Vercel.
